A minimal, dependency-free TypeScript package (`@rentlite/shared`) whose sole purpose is to centralize type definitions. `src/index.ts` re-exports everything from `src/types.ts`, which groups types by domain: Property/Unit, Tenant/Lease, Payment, MaintenanceRequest, Expense, Vendor, Notification, Subscription, Dashboard/Report aggregates, and generic API error/pagination wrappers. The package has no runtime dependencies — only `typescript` as a devDependency — and publishes both ESM entry points (`dist/index.js`, `dist/index.d.ts`) via `package.json` `exports` so consumers can import it as a pure type contract without pulling in any code.
