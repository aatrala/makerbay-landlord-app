Single-page application bootstrapped in `src/main.tsx` with a layered composition: global providers (`QueryClientProvider`, `AuthProvider`) wrap the root, `App.tsx` declares routes via wouter's `<Switch>`/`<Route>`, and protected routes wrap feature pages inside `AppLayout`. Feature pages live under `src/pages/` (Dashboard, Properties, Tenants, Payments, Maintenance, Expenses, Reports) and consume shared state through `src/contexts/auth-context.tsx`, which wraps better-auth's `useSession` into a simple `isAuthenticated` / `user` shape. Data fetching is centralized in `src/lib/api.ts` as an `ApiClient` class that builds URLs from `VITE_API_URL`, attaches JSON headers and session cookies, and redirects on 401; business logic pages call this client directly or via TanStack Query hooks. UI is split into reusable primitives under `src/components/ui/` (Button, Card, Input, Badge, StatCard) and a layout shell in `src/components/layout/AppLayout.tsx`. The build is configured by `vite.config.ts` with Tailwind v4, a `@` path alias to `src/`, and a dev proxy forwarding `/api` to `http://localhost:3000`; Dockerfile builds via pnpm workspace filtering `@rentlite/shared` then `client`.
