The `src/index.ts` entrypoint bootstraps a single Express application, registers global middleware (CORS, JSON parsing), mounts the Better-Auth handler at `/api/auth/*`, and mounts each feature's router under its own `/api/<resource>` prefix (properties, units, tenants, leases, payments, expenses, vendors, reports, dashboard). All routers share cross-cutting concerns provided by sibling modules: `auth/middleware.ts` supplies ownership-scoped authorization, `db/` exports Drizzle ORM schema, relations, and client used by every route, and `email/resend.ts` is consumed by routes that send notifications. The app is containerized via Dockerfile and uses `tsx watch` for development with TypeScript ESM throughout.
