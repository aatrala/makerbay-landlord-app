The root defines a pnpm workspace (`pnpm-workspace.yaml`) declaring three packages — `shared`, `server`, `client` — with the top-level `package.json` scripts orchestrating them via `pnpm --filter`. The `shared` package is built first and consumed by both `server` (Express routes, auth, DB, email) and `client` (Vite+React SPA), providing the single source of truth for domain models and API shapes. `docker-compose.yml` wires the runtime: a PostgreSQL 16 container, the server container depending on it, and the client container depending on the server, exposing ports 5432/3000/5173. Environment variables flow from `.env.example` into compose, so all services share the same configuration surface (DATABASE_URL, BETTER_AUTH_* keys, RESEND/TWILIO/PLAID credentials).
